🔒 About Ephemeral

Ephemeral is an independent project created just for fun, experimentation, and learning by Priyanshu Kumar, a tech creator and developer currently pursuing a B.S. in Data Science and Applications.

The idea behind Ephemeral is to explore a different approach to online communication, where conversations and media can be temporary rather than permanently stored.

This project is an independent experiment built to learn, create, and explore what is possible with modern web technologies.
